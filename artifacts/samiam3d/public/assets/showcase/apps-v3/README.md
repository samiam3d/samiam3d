# Application showcase visuals

Ten designed product visualizations created with the built-in image generation tool, using the real apps and their original branding as references. These are portfolio illustrations of source-confirmed workflows, not live screenshots. Demo content is fictional.

All images are 1672 × 941 WebP files. Only format conversion and compression were applied after generation. The original brand assets remain in the site's brands directory.

Each provenance file preserves the final prompts, reference assets, generation mode, and output details. The site presents each pair in its application's full-width section and identifies the imagery as product visualizations.
